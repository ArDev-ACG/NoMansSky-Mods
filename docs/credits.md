## Material de referencia (NO redistribuible)

`asset/necro/` contiene escaneos de *The Art of Dead Space* (© EA / Visceral Games).
Uso: **referencia visual únicamente**. Mirar arte para inspirarse es normal.

Reglas duras:
- No entra a git. Bloqueado en `.gitignore`.
- No entra a ningún `.pak` ni release de Nexus.
- No se calca ni se traza sobre él para generar texturas del mod. La inspiración
  es libre; la copia derivada no.

Mismo criterio para cualquier otro material de referencia que se añada después.

**Regla:** muchos mods de NMS prohíben reusar sus assets. Antes de usar cualquier
cosa ajena — modelo, textura, script — verificar permisos y pedir autorización.
Todo lo que se use va anotado aquí con autor, link y permiso concedido.
